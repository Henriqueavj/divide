# Divide

App simples para dividir gastos em viagens e grupos, inspirado no fluxo do Splitwise.

- Funciona offline e pode ser instalado na tela inicial do celular.
- Os dados (grupos, pessoas, gastos e acertos) ficam só no aparelho, no navegador. Nada é enviado para servidor.
- Para levar os dados para outro aparelho: aba Conta → Exportar dados, e no outro aparelho Importar dados.

Tudo está em `index.html` (HTML, CSS e JavaScript sem dependências). `sw.js` guarda o app para uso offline.
